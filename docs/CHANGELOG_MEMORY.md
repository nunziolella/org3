# Strategic Changelog

This changelog records important product decisions rather than every technical commit.

## 2026-07-01 — Initial product definition

### Context

AIProd originated from the need to manage many connected responsibilities, ideas and projects without using the mind as the primary storage and prioritisation system.

### Decision

Define AIProd as an AI-first personal operating system rather than a generic task manager or AI chat.

### Core loop

Capture → classify → connect → prioritise → execute → review.

### Primary objects

- Areas;
- Projects;
- Tasks;
- Inbox Items;
- Ideas;
- Notes;
- Reviews;
- Relations;
- AI Proposals.

### Product constraints

- Not every idea becomes active.
- Active projects must remain limited.
- AI changes must be reviewable.
- Raw input must remain traceable.
- The interface must reduce complexity instead of exposing all relationships by default.

### Design direction

- modern dark interface;
- bento box layout;
- glassmorphism;
- premium AI-product aesthetic;
- responsive design;
- calm visual hierarchy.

### Documentation status

The repository documentation represents the intended product specification. The actual implementation must be reconciled with it once the complete Emergent source code is available.
